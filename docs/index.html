Recalibrated SOFA-derived score

Estimates ICU mortality risk from first-day physiology using data-driven cut-points and integer weights. Not a substitute for the conventional SOFA assessment.

Risk estimation is off. Set CALIBRATION.ready in the script to enable it.
Research use only. Developed and internally validated in eICU-CRD; external and prospective validation are still required before use in patient care.
